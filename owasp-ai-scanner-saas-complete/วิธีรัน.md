# คำแนะนำการรันระบบ - ฉบับสมบูรณ์

## ขั้นตอนที่ 1: ติดตั้ง Dependencies

```bash
cd owasp-ai-scanner-saas-complete/backend
npm install
```

## ขั้นตอนที่ 2: สร้างไฟล์ .env

สร้างไฟล์ `.env` ในโฟลเดอร์ `backend` และใส่ข้อมูลต่อไปนี้:

```env
# Google Gemini API Key (รับได้ฟรีจาก https://aistudio.google.com/app/apikey)
GEMINI_API_KEY=ใส่_API_KEY_ของคุณ

# Server Port
PORT=3001

# ZAP Configuration
ZAP_URL=http://localhost:8081
ZAP_API_KEY=m67ag15c1cjvo56nad6hlemurk
```

**หมายเหตุ:** ต้องสมัคร Google Gemini API Key ก่อน
1. ไปที่ https://aistudio.google.com/app/apikey
2. สร้าง API Key (ฟรี)
3. Copy มาใส่ในไฟล์ .env

## ขั้นตอนที่ 3: รัน OWASP ZAP (Terminal 1)

เปิด Terminal แรกแล้วรัน Docker:

```bash
docker run -u zap -p 8081:8081 -i ghcr.io/zaproxy/zaproxy:stable zap.sh -daemon -host 0.0.0.0 -port 8081 -config api.addrs.addr.name=.* -config api.addrs.addr.regex=true -config api.key=m67ag15c1cjvo56nad6hlemurk
```

**รอจนกว่า ZAP จะรันสำเร็จ** (ประมาณ 30 วินาที - 1 นาที)
จะเห็นข้อความ: `ZAP is now listening on localhost:8081`

## ขั้นตอนที่ 4: รัน Backend (Terminal 2)

เปิด Terminal ใหม่ (Terminal ที่ 2):

```bash
cd owasp-ai-scanner-saas-complete/backend
npm start
```

**รอจนกว่า Backend จะรันสำเร็จ**
จะเห็นข้อความ:
```
[v0] SecureScan server running on port 3001
[v0] Health check: http://localhost:3001/health
```

## ขั้นตอนที่ 5: เปิด Frontend (Terminal 3)

เปิด Terminal ใหม่ (Terminal ที่ 3):

**วิธีที่ 1: ใช้ Live Server (แนะนำ)**
```bash
cd owasp-ai-scanner-saas-complete/frontend
npx serve -p 5500
```

**วิธีที่ 2: เปิดไฟล์โดยตรง**
- เปิดไฟล์ `frontend/index.html` ในเบราว์เซอร์
- ขวาคลิก > Open with Live Server (ถ้ามี VS Code Extension)

## ขั้นตอนที่ 6: ทดสอบระบบ

เปิดเบราว์เซอร์ไปที่: `http://localhost:5500`

**ทดสอบสแกน:**
1. กรอก URL เช่น: `http://testphp.vulnweb.com`
2. คลิก "เริ่มการสแกน"
3. รอประมาณ 2-5 นาที (ขึ้นอยู่กับขนาดเว็บไซต์)
4. ดูผลลัพธ์ที่วิเคราะห์ด้วย AI

## แก้ปัญหา

### ปัญหา: พอร์ต 8081 ถูกใช้แล้ว
```bash
# หาโปรเซสที่ใช้พอร์ต
netstat -ano | findstr :8081

# ปิดโปรเซส (Windows)
taskkill /PID <หมายเลข PID> /F
```

### ปัญหา: ZAP ไม่เชื่อมต่อ
ตรวจสอบว่า:
1. Docker รันอยู่
2. ZAP_API_KEY ตรงกันทั้งใน Docker command และไฟล์ .env
3. ลองรัน: `curl http://localhost:8081/JSON/core/view/version/`

### ปัญหา: ไม่เจอช่องโหว่
1. ใช้เว็บทดสอบ: `http://testphp.vulnweb.com`
2. ตรวจสอบ logs ใน Terminal Backend
3. เว็บบางเว็บอาจปลอดภัยจริงๆ หรือบล็อก scanner

### ปัญหา: Backend Error "GEMINI_API_KEY not found"
1. สร้างไฟล์ `.env` ในโฟลเดอร์ backend
2. ใส่ GEMINI_API_KEY (สมัครได้ฟรีที่ https://aistudio.google.com/app/apikey)

4. **เว็บทดสอบ**: ใช้เว็บทดสอบอย่าง testphp.vulnweb.com
5. **กฎหมาย**: อย่าสแกนเว็บที่ไม่ได้รับอนุญาต (ผิดกฎหมาย)
