บทคัดย่อ

โปรเจคนี้พัฒนาขึ้นเพื่อช่วยตรวจสอบช่องโหว่ด้านความปลอดภัยของเว็บไซต์โดยอัตโนมัติ โดยใช้เครื่องมือ OWASP ZAP ในการสแกนและวิเคราะห์ร่วมกับ Google Gemini AI เพื่ออธิบายผลลัพธ์เป็นภาษาไทยที่เข้าใจง่าย พร้อมคำแนะนำวิธีแก้ไขอย่างละเอียด ระบบนี้ช่วยให้ผู้ดูแลเว็บไซต์สามารถทราบและแก้ไขช่องโหว่ได้อย่างรวดเร็วและถูกต้อง

ทดสอบระบบ

กรุณากรอก URL ของเว็บไซต์ที่ต้องการตรวจสอบ ระบบจะทำการสแกนหาช่องโหว่และวิเคราะห์ผลด้วย AI

เทคโนโลยีที่ใช้

OWASP ZAP

เครื่องมือสแกนช่องโหว่ Open Source ที่ได้รับการยอมรับในระดับสากล

Google Gemini AI

AI Model สำหรับวิเคราะห์และอธิบายผลลัพธ์เป็นภาษาไทย

Node.js & Express

Backend Framework สำหรับจัดการ API และเชื่อมต่อระบบต่างๆ

HTML/CSS/JavaScript

Frontend Technologies สำหรับแสดงผลและ User Interface
